These fields are hidden from end users. Provide them through your backend integration only.

| Field | Requirement | Description |
|---|---|---|
| `redirectUrl` | <Opt /> | URL to redirect to after the OAuth flow. If empty or not set, the user is redirected to the white label Web Banking. |
| `state` | <Opt /> | Opaque value passed through the OAuth flow to prevent XSRF attacks. If not set, Swan fills it with the onboarding ID. |
