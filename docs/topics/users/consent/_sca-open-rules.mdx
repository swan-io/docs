:::caution Open Swan pages in the top-level browser only
Don't open Swan's authorization, consent, or sensitive card information pages:

- In an iframe
- In a WebView
- In a popup (for example, with `window.open`)

Swan no longer supports these flows, and they stop working from 31 December 2026.

Instead, redirect the user to the URL:

- On the web, in the current browser tab.
- In a mobile app, in the device's browser or an in-app browser tab (`SFSafariViewController` on iOS, Chrome Custom Tabs on Android).
:::
