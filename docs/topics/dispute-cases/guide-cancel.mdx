# Cancel a dispute case

Cancel a draft dispute case **with the API** when you no longer need it.
For example, the draft was created by mistake, a network retry created a duplicate, or your user decides not to report the transactions.

You can only cancel drafts.
To withdraw a submitted case, ask in the case's support ticket.

:::tip Prerequisites
- The case is a `Draft`.
- You have a [project access token](/developers/using-api/authentication/guide-get-token-project), or a [user access token](/developers/using-api/authentication/guide-get-token-user) for a user with the right [permissions](./index.mdx#permissions).
:::

## Guide {#guide}

1. Call the `cancelDisputeCase` mutation.
1. Add the `disputeCaseId` (line 2).
1. Add the success payload (line 3).
1. Add [rejections](./index.mdx#rejections) (not shown).

mutation CancelDisputeCase {
  cancelDisputeCase(input: { disputeCaseId: "$DISPUTE_CASE_ID" }) {
    ... on CancelDisputeCaseSuccessPayload {
      __typename
      disputeCase {
        id
        statusInfo {
          status

            canceledAt
          }
        }
      }
    }
  }

## Payload {#payload}

The case is `Canceled` (line 8).
It's kept, but can't be updated or submitted.

    "cancelDisputeCase": {

        "id": "$DISPUTE_CASE_ID",

        }
