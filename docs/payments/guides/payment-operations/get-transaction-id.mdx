# Get a transaction ID

Get transaction IDs with the `transactions` query. To find them on your Dashboard instead, [look up transactions from the Dashboard](/payments/guides/payment-operations/from-the-dashboard#transaction-id).

## Guide {#guide}

Queries are highly customizable.
This guide focuses solely on using the `transactions` query to get transaction IDs. 
Learn more about this query in the guide to [get transaction information](/payments/guides/payment-operations/get-transaction-info).

1. Call the `transactions` query.
1. Check the boxes for `edges` and `node`.
1. Under `node`, check the boxes for `id`, `createdAt`, and `label`.
    * `label` often contains a name, which might be helpful.
    * `createdAt` could help you identify the transaction ID you're searching for if you know when the payment was initiated.
    * Additionally, you might choose to get only the `first` 10 IDs on the list, use [pagination](/build/using-api/pagination) to filter further, or add a `totalCount`.

### Query {#query}

<a href="https://explorer.swan.io?query=cXVlcnkgR2V0VHJhbnNhY3Rpb25JZCB7CiAgdHJhbnNhY3Rpb25zIHsKICAgIGVkZ2VzIHsKICAgICAgbm9kZSB7CiAgICAgICAgaWQKICAgICAgICBjcmVhdGVkQXQKICAgICAgICBsYWJlbAogICAgICB9CiAgICB9CiAgICB0b3RhbENvdW50CiAgfQp9Cg%3D%3D&tab=api" className="explorer-badge">Open in API Explorer</a>

```graphql {2,5-7,10} showLineNumbers
query GetTransactionId {
  transactions {
    edges {
      node {
        id
        createdAt
        label
      }
    }
    totalCount
  }
}

```
