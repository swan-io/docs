# Add a virtual IBAN from the Dashboard

Add a virtual <Term id="ibans">IBAN</Term> to an account from your Dashboard.

import AddVirtualPrerequisites from '../partials/_add-virtual-prereqs.mdx';

:::tip Prerequisites
Your Dashboard membership has write access to accounts (`dataAccount_write` permission).

<AddVirtualPrerequisites />
:::

## Steps {#steps}

1. On your Dashboard, go to **Data** > **Accounts**.
1. Select the account.
1. Open the **Virtual IBANs** tab.
1. Click **+ New** to add a virtual IBAN to the account.

The **+ New** button is only available when both prerequisites are met.
