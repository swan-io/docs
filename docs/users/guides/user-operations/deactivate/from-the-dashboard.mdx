You can deactivate a user directly from your Dashboard.

## Before you start {#before-you-start}

All of the following conditions must be met:

Review the [deactivation concept](/users/concepts/user/deactivation) for the full model, including rejection reasons.

## Steps {#steps}

1. On your Dashboard, go to **Data** > **Users**.
1. Open the user you need to deactivate and deactivate them.

If the user doesn't meet the [conditions above](#before-you-start), the Dashboard displays an error and the user isn't deactivated.

## Find deactivated users {#find}

Deactivated users don't appear in the default user list.
To review them, filter the user list by **status**.
The user's deactivation date is displayed in their detail view.
