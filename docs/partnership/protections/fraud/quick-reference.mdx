# Fraud quick-reference card

Use this checklist when a user reports fraud.
For details, see the [Support team fraud response playbook](./support-playbook.mdx).

## 1. Secure immediately {#secure}

Ask the user to:

- [ ] Stop replying to the fraudster.
- [ ] Stop clicking links and approving operations.
- [ ] Change their passwords from official websites or apps, including their email account.
- [ ] Block or cancel their card if it's compromised.
- [ ] Turn on MFA or 2FA when available.

## 2. Check the essentials {#check}

- [ ] The account and user affected.
- [ ] The card or transactions involved.
- [ ] What the user shared with the fraudster.
- [ ] Operations made or attempted.
- [ ] New beneficiaries, devices, or account members.
- [ ] Other users who might be affected.

## 3. Keep the evidence {#evidence}

Ask the user to keep:

- [ ] Emails and text messages.
- [ ] Screenshots.
- [ ] Phone numbers, email addresses, and links.
- [ ] Transaction references.
- [ ] Dates and times of the exchanges.

## 4. Report to Swan {#report}

- [ ] **Completed transactions**: create a [fraud dispute case](/topics/dispute-cases/#fraud) with the **Fraud report** form in your Dashboard.
- [ ] **No transaction yet, or account suspension needed**: submit a [Swan Support request](https://partner-support.swan.io/hc/en-gb/requests/new).
- [ ] Include the **account ID**, and the **account membership ID** and **card ID** when relevant.

:::caution
Never ask users for their password, MFA code, or one-time code.
:::
