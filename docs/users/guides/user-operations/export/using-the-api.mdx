# Export user data using the API

Export the user data available on the Dashboard as a `.csv` file, programmatically.

## Guide {#guide}

1. Call the `exportUserData` mutation.
1. Optionally, add your `email` (line 4). A link to download the `.csv` export is sent to the email address you provide. If you don't include an email, the download link is only available from the Dashboard.
1. Optionally, add `filters` (line 5) to narrow the export: user status, nationality, identification level, preferred notification channel, mobile phone number, birthdate, or a search string.
1. Add the success payload, including the `exportId` (line 10), and rejections.

```graphql {4,5,10} showLineNumbers
mutation ExportUsers {
  exportUserData(
    input: {
      email: "$YOUR_EMAIL_ADDRESS"
      filters: { status: Active }
    }
  ) {
    ... on ExportDataSuccessPayload {
      __typename
      exportId
    }
    ... on MaximumSimultaneousExportsRejection {
      __typename
      message
    }
    ... on MaximumDailyExportsReachedRejection {
      __typename
      message
    }
  }
}
```

### Mutation fields {#mutation-input}

<FieldRequirementsLegend />

| Field | Type | | Description |
| --- | --- | --- | --- |
| `email` | `String` | <Opt /> | Email address that receives the link to download the export. |
| `filters` | `ExportUserDataFilters` | <Opt /> | Filters to narrow the export. |

## Payload {#payload}

The payload returns the export ID.

```json {5} showLineNumbers
{
  "data": {
    "exportUserData": {
      "__typename": "ExportDataSuccessPayload",
      "exportId": "$EXPORT_ID"
    }
  }
}
```

After finalizing your export, [a download link is sent to the email address you provided](/users/guides/user-operations/export#after-you-export).
