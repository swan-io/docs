# Main IBANs

Every Swan account has one main <Term id="ibans">IBAN</Term>.
All [virtual IBANs](/accounts/concepts/ibans/virtual) are connected to the main IBAN.

## How the main IBAN works {#how-it-works}

The [`PaymentAccountType`](/accounts/concepts/account/type-and-level) changes from `EMoney` to `PaymentService` when the account's main IBAN is available.
The account's `PaymentLevel` can be `Limited` even if the main IBAN is available.
