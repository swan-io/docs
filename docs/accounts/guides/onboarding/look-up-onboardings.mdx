# Look up onboardings from the Dashboard

Review your project's <Term id="account-onboarding">onboardings</Term> from your Dashboard, without calling the API.

## Steps {#steps}

1. Go to **Dashboard** > **Data** > **Onboardings**.

The list includes the `onboardingId`; it's the only ID included on that list.
To export onboarding data instead, [export from the Dashboard or with the API](/accounts/guides/onboarding/export).
