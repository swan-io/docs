## Before you start {#before-you-start}

Exports cover all of your project's account memberships.
To narrow the export, filter by account, member email, permissions, or membership status.

Review the [memberships concept](/accounts/concepts/memberships) for the full model.

## What's included in an export {#included}

Every export contains the same fields, regardless of path:

- Membership ID, email, language, and tax identification number
- User ID, first name, all first names, last name, and birth last name
- User birth date, birth country, and mobile phone number
- Account ID and account country
- Created, last-updated, and disabled timestamps
- Each [membership permission](/accounts/reference/memberships/membership-permissions#permissions)
- Number of cards
- [Membership status](/accounts/concepts/memberships/statuses#statuses)
- Legal-representative status
- Accepted [identification levels](/users/concepts/identifications/levels-processes), and whether the user has the required level
