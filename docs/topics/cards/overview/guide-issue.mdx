# Issuing cards

Issue both digital and physical bank cards with custom or standard designs to users.

## Prerequisites

Before issuing cards, ensure each user:

- is a member of the relevant account
- has an assigned [card language](../index.mdx#language)

## Steps

### 1: Choose a standard or custom design

→ [Standard designs](../design/guide-standard.mdx)

→ [Custom designs](../design/guide-custom.mdx)

### 2: Choose the packaging

These are available for both design types.

→ [Packaging](../design/index.mdx#packaging)

### 3: Add one or multiple account members

→ [Adding one account member](../../accounts/memberships/guide-add-one.mdx)

→ [Adding multiple account members](../../accounts/memberships/guide-add-multiple.mdx)

### 4: Issue one or more virtual cards

:::tip
You can print physical cards at the same time as issuing them virtually. See [Printing a physical card when issuing a virtual card](../virtual/guide-add.mdx#print-with-virtual).
:::

→ [Issue one virtual card](../virtual/guide-add.mdx#add-one)

→ [Issue multiple virtual cards](../virtual/guide-add.mdx#add-multiple)

Immediately after issuing a virtual card, it's available for eCommerce transactions.

### Digitize or print the virtual card

→ [Printing one physical card](../physical/guide-print.mdx#print-one)

→ [Printing multiple physical cards with group delivery](../physical/guide-print.mdx#print-group)

### View sensitive card information

Processing transactions requires the card number and other sensitive information.

→ [Viewing a virtual card's sensitive information](../virtual/guide-view-info.mdx)

### Update card settings

You can update the settings for a [card product](../index.mdx#card-product) at any time.
Settings apply to all card types: virtual, physical, and digital.

→ [Updating card settings](../overview/guide-update.mdx)
