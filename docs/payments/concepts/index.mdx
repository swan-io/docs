# Payments concepts

<p className="ia-lede">The models behind Swan <Term id="payments">payments</Term>: how a payment groups <Term id="transactions">transactions</Term>, the payment methods, and the merchant side.</p>

## How payments work {#how-payments-work}

A payment is a request to move money. Each payment groups one or more transactions, which are what actually credit and debit accounts.
