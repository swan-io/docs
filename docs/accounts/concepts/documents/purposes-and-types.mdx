# Document purposes and types {#document-purposes-types}

For all <Term id="supporting-documents">supporting documents</Term>, there is a high-level **purpose** and a more specific **type** (`supportingDocumentPurpose` and `supportingDocumentType`).
Both purpose and type can be exposed in the onboarding success payload.

## Common purposes {#purposes}

**Common purposes** (not exhaustive):

* `CompanyRegistration`
* `SignedStatus`
* `ProofOfIndividualAddress` and `ProofOfCompanyAddress`
* `ProofOfIndividualIncome` and `ProofOfCompanyIncome`
* `ProofOfBusinessActivity`
* `USPersonStatusDeclaration`
* `Other`

:::info `purposeDetails` for `Other` purposes
`purposeDetails` is an optional field available on the `SupportingDocumentPurpose` type (returned under `requiredSupportingDocumentPurposes`).

When the requested purpose is `Other`, `purposeDetails` contains free-text details that specify what supporting document is required (for example, "Company structure chart").

For [standard purposes](https://api-reference.swan.io/enums/supporting-document-purpose-enum/) (predefined purposes with a specific meaning, such as `ProofOfIndividualAddress` or `CompanyRegistration`), `purposeDetails` is `null`.
:::

## Document types {#types}

Types are the specific documents that can fulfill a purpose.
Each purpose accepts a set of types, returned in the `acceptableSupportingDocumentTypes` field.
For all possible values, refer to the [`SupportingDocumentType` enum](https://api-reference.swan.io/enums/supporting-document-type/) in the API Reference.
