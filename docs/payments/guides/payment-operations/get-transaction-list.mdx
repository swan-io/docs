# Get a list of transactions

You can **call the API** to get a list of all <Term id="transactions">transactions</Term> executed from an account.

Transaction information is also available [from the Dashboard](/payments/guides/payment-operations/from-the-dashboard), as well as Swan's Web Banking interface if you're using it.

:::tip Prerequisites
You need a **project access token** to call the query.
:::

## Guide {#guide}

1. Call the `account` query.
1. Add the account ID.
1. Add all information you'd like to review about each transaction. This example queries for transactions with the status `Upcoming`, retrieves their future `executionDate`, and [includes the `reference`](/payments/concepts/credit-transfers#label-reference).
1. Add [pagination](/build/using-api/pagination#arguments) if you're looking for transactions for a certain interval, or you're expecting a long list.

```graphql {2,9,24,26} showLineNumbers
query UpcomingTransactions {
  account(accountId: "$YOUR_ACCOUNT_ID") {
    balances {
      available {
        currency
        value
      }
    }
    transactions(first: 2, filters: { status: Upcoming }) {
      edges {
        node {
          amount {
            value
            currency
          }
          id
          type
          label
          createdAt
          reference
          side
          updatedAt
          statusInfo {
            ... on UpcomingTransactionStatusInfo {
              __typename
              executionDate
            }
          }
        }
      }
      totalCount
    }
  }
}
```
