# Get dispute case information

Retrieve dispute cases **with the API**.
For example, show a case's status to your user, find a draft to resume, or check whether a transaction was already reported.

You can only retrieve cases you're allowed to see. See [permissions](./index.mdx#permissions).

## Get a case {#case}

### Guide {#case-guide}

1. Call the `disputeCase` query with the case ID (line 2).
1. Add the information you want, such as the status and the transactions (lines 3-18).
1. Add `... on FraudDisputeCase` for fields specific to fraud dispute cases (line 19).

```graphql {2,4,7,19} showLineNumbers
query GetDisputeCase {
  disputeCase(disputeCaseId: "$DISPUTE_CASE_ID") {
    id
    statusInfo {
      status
    }
    reportedTransactions(first: 100) {
      edges {
        node {
          id
          amount {
            value
            currency
          }
          executionDate
        }
      }
    }
    ... on FraudDisputeCase {
      fraudDetails {
        reportedReason
        reportedTypology
      }
    }
  }
}
```

## List an account's cases {#account}

### Guide {#account-guide}

1. Call the `account` query and add `disputeCases` (line 3).
1. Optionally, filter by `type`, `status`, `externalReference`, or `transactionIds` (line 5).
   This example finds drafts that include a transaction, for example before retrying a failed `draftFraudDisputeCase`.
1. Add the information you want (lines 7-17).

### Query {#account-query}

<a href="https://explorer.swan.io?query=cXVlcnkgQWNjb3VudERyYWZ0RGlzcHV0ZUNhc2VzIHsKICBhY2NvdW50KGFjY291bnRJZDogIiRBQ0NPVU5UX0lEIikgewogICAgZGlzcHV0ZUNhc2VzKAogICAgICBmaXJzdDogMjAKICAgICAgZmlsdGVyczogeyB0cmFuc2FjdGlvbklkczogWyIkVFJBTlNBQ1RJT05fSUQiXSwgc3RhdHVzOiBbRHJhZnRdIH0KICAgICkgewogICAgICBlZGdlcyB7CiAgICAgICAgbm9kZSB7CiAgICAgICAgICBpZAogICAgICAgICAgc3RhdHVzSW5mbyB7CiAgICAgICAgICAgIHN0YXR1cwogICAgICAgICAgICAuLi4gb24gRGlzcHV0ZUNhc2VEcmFmdFN0YXR1c0luZm8gewogICAgICAgICAgICAgIGV4cGlyZXNBdAogICAgICAgICAgICB9CiAgICAgICAgICB9CiAgICAgICAgfQogICAgICB9CiAgICB9CiAgfQp9Cg%3D%3D&tab=api" className="explorer-badge">Open in API Explorer</a>

```graphql {3,5} showLineNumbers
query AccountDraftDisputeCases {
  account(accountId: "$ACCOUNT_ID") {
    disputeCases(
      first: 20
      filters: { transactionIds: ["$TRANSACTION_ID"], status: [Draft] }
    ) {
      edges {
        node {
          id
          statusInfo {
            status
            ... on DisputeCaseDraftStatusInfo {
              expiresAt
            }
          }
        }
      }
    }
  }
}
```

## List a transaction's cases {#transaction}

### Guide {#transaction-guide}

1. Call the `transaction` query and add `disputeCases` (line 4).
1. Filter by `status: [Submitted]` to check whether the transaction was already reported.

The root `transaction` query needs a project access token.
With a user access token, select `disputeCases` on transactions from `Account.transactions` instead.

### Query {#transaction-query}

<a href="https://explorer.swan.io?query=cXVlcnkgVHJhbnNhY3Rpb25EaXNwdXRlQ2FzZXMgewogIHRyYW5zYWN0aW9uKGlkOiAiJFRSQU5TQUNUSU9OX0lEIikgewogICAgaWQKICAgIGRpc3B1dGVDYXNlcyhmaXJzdDogMSwgZmlsdGVyczogeyBzdGF0dXM6IFtTdWJtaXR0ZWRdIH0pIHsKICAgICAgZWRnZXMgewogICAgICAgIG5vZGUgewogICAgICAgICAgaWQKICAgICAgICB9CiAgICAgIH0KICAgIH0KICB9Cn0K&tab=api" className="explorer-badge">Open in API Explorer</a>

```graphql {4} showLineNumbers
query TransactionDisputeCases {
  transaction(id: "$TRANSACTION_ID") {
    id
    disputeCases(first: 1, filters: { status: [Submitted] }) {
      edges {
        node {
          id
        }
      }
    }
  }
}
```

### Payload {#transaction-payload}

The transaction was already reported in a submitted case. The list is always empty for transactions that can't be reported.

```json title="Payload" showLineNumbers
{
  "data": {
    "transaction": {
      "id": "$TRANSACTION_ID",
      "disputeCases": {
        "edges": [
          {
            "node": {
              "id": "$DISPUTE_CASE_ID"
            }
          }
        ]
      }
    }
  }
}
```
