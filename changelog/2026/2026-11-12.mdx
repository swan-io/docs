## API updates

### Upcoming breaking changes

🏦 **Breaking change.** From **November 12, 2026**, the `extra.additional_information` field in Account Information Service (AIS) transaction responses returns the Origin Transaction ID (`originTransactionId`) instead of the Payment ID (`paymentId`). The Payment ID is no longer available through AIS.

This lets accounting tools, such as DATEV in Germany, link a fee transaction back to its origin transaction for easier reconciliation.

If your integration reads the Payment ID from this field, update it before **November 12, 2026**. Details are on the [AIS page](/topics/open-banking/ais/#field-mapping).
