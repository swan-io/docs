# Payment statuses

<p className="ia-lede">The status flow for <a href="/payments/concepts/payments">payments</a>. A requested payment waits for <Term id="consent">consent</Term> when consent is required, then either enters the transaction flow or is rejected.</p>

## Statuses {#payments-statuses}

```mermaid
%%{ init: { 'flowchart': { 'curve': 'linear' } } }%%
flowchart LR
    P((Payment<br/>requested)) -.-> I[Initiated]
    P -.-> CP[ConsentPending]
    CP -.-> RJ[Rejected]
    P -.-> RJ
    CP -.-> I
    I -.-> RJ
    subgraph F[Final status]
        RJ
    end
    style P fill:#D4D3D5,stroke:#514F59
    style F fill:#fffdf4,stroke:#cca922
```

| Payment status | Explanation |
|---|---|
| `ConsentPending` | Status only occurs when consent is required for the payment<br/><br/>**Next step**: Transaction flow blocked while waiting for <Term id="consent">consent</Term>; when consent is received, transaction flow resumes and payment status changes to `Initiated` |
| `Initiated` | Payment successfully requested; enters the [transaction flow](/payments/concepts/transactions/statuses#transactions-statuses) |
| `Rejected` | Payment rejected, either directly after payment initiation or from the `Initiated` status |
