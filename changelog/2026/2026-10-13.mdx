## Improvements

🇫🇷 **Birth postal code only for users born in France**: Swan now asks for the birth postal code at sign-up only when the user is born in France and the account is in France. You no longer need to collect or prefill it otherwise. Check the [individual](/topics/onboarding/individual/fields/#birth-information) and [company](/topics/onboarding/company/fields/#administrator-birth-information) onboarding fields pages for details.
