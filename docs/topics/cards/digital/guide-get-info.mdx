# Get digital card information

Get information about a digital card with the API, including its status and the card it belongs to.

:::tip Prerequisites
You need a [project access token](../../../developers/using-api/authentication/index.mdx#tokens-project) to call the query.
You can also use a [user access token](../../../developers/using-api/authentication/index.mdx#tokens-user) if the user is the cardholder, or an account member with both the `canManageAccountMembership` and `canManageCards` [permissions](../../accounts/memberships/index.mdx#permissions).
:::

## Guide {#guide}

1. Call the `digitalCard` query.
1. Enter your digital card ID (line 2). If you're resolving a `DigitalCard.Created` or `DigitalCard.Updated` webhook event, use the event's `resourceId`. Learn more about [tracking digital card changes](/topics/cards/digital/#tracking-status).
1. Add the information you need. This sample returns the status of a card that's still pending: `ConsentPending`, `Pending`, or `Declined` (line 8). For a card that finished provisioning, replace the fragment with `... on CompleteDigitalCard` to get `Enabled`, `Suspended`, or `Canceled`.

```graphql {2,8} showLineNumbers
query getDigitalCard {
  digitalCard(digitalCardId: "$YOUR_DIGITAL_CARD_ID") {
    id
    type
    cardId
    ... on PendingDigitalCard {
      statusInfo {
        status
      }
    }
  }
}
```
