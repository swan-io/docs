# Get card package tier

Retrieve the <Term id="card-package">card package</Term> tier assigned to a specific card using the `card` query. Card package tiers: `Standard`, `Essential`, and `Premium`.

## Retrieve card package tier {#guide-main}

1. Call the `card` query.
1. Enter the `cardId` (line 2).
1. Add `cardPackage` to receive the card package tier (line 4).

### Query {#query-main}

<a href="https://explorer.swan.io/?query=cXVlcnkgUmV0cmlldmVDYXJkUGFja2FnZSB7CiAgY2FyZChjYXJkSWQ6ICIkWU9VUl9DQVJEX0lEIikgewogICAgaWQKICAgIGNhcmRQYWNrYWdlCiAgfQp9Cg%3D%3D&tab=api" className="explorer-badge">Open in API Explorer</a>

```graphql {2,4} showLineNumbers
query RetrieveCardPackage {
  card(cardId: "$YOUR_CARD_ID") {
    id
    cardPackage
  }
}
```

### Payload {#payload-main}

The response includes the `cardPackage` (line 5), `Premium` in this example. Possible values: `Standard`, `Essential`, or `Premium`.

```json {5} showLineNumbers
{
  "data": {
    "card": {
      "id": "$YOUR_CARD_ID",
      "cardPackage": "Premium"
    }
  }
}
```
