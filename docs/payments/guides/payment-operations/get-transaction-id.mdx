# Get a transaction ID

Get transaction IDs with the `transactions` query. To find them on your Dashboard instead, [look up transactions from the Dashboard](/payments/guides/payment-operations/from-the-dashboard#transaction-id).

## Guide {#guide}

1. Call the `transactions` query.
1. Add `edges` > `node` > `id`, `createdAt`, and `label`.
    * `label` often contains a name, as in the sample.
    * `createdAt` could help you identify the transaction ID you're searching for if you know when the transaction was created.
    * Add `first` to cap the list (the sample asks for 10), use [pagination](/build/using-api/pagination) to go further, or add a `totalCount`.

### Query {#query}

<a href="https://explorer.swan.io?query=cXVlcnkgR2V0VHJhbnNhY3Rpb25JZCB7CiAgdHJhbnNhY3Rpb25zKGZpcnN0OiAxMCkgewogICAgZWRnZXMgewogICAgICBub2RlIHsKICAgICAgICBpZAogICAgICAgIGNyZWF0ZWRBdAogICAgICAgIGxhYmVsCiAgICAgIH0KICAgIH0KICAgIHRvdGFsQ291bnQKICB9Cn0K&tab=api" className="explorer-badge">Open in API Explorer</a>

```graphql {2,5-7,10} showLineNumbers
query GetTransactionId {
  transactions(first: 10) {
    edges {
      node {
        id
        createdAt
        label
      }
    }
    totalCount
  }
}
```
