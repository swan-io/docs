## Before you start {#before-you-start}

Exports cover all of your project's account memberships.
To narrow the export, filter by account, member email, permissions, or membership status.

Review the [memberships concept](/accounts/concepts/memberships) for the full model.

## What's included in an export {#included}

Every export contains the same fields, regardless of path:

- Membership ID, email, permissions, and legal-representative status
- Account ID and account name
- Invitation status (pending, accepted, suspended, or disabled)
- Created and last-updated timestamps
- Binding errors, if any
