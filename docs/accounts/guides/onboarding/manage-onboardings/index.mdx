## Before you start {#before-you-start}

You need at least one existing onboarding, either [individual](/accounts/guides/onboarding/individual/create) or [company](/accounts/guides/onboarding/company/create).

To export onboarding data instead, [export from the Dashboard or with the API](/accounts/guides/onboarding/export).
Review the [onboarding concept](/accounts/concepts/onboarding) for the model and [statuses](/accounts/concepts/onboarding/statuses).
