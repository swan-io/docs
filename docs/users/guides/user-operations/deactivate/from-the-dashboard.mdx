# Deactivate a user from the Dashboard

:::caution Work in progress
This guide is being completed.
The exact Dashboard steps are pending verification.
:::

You can deactivate a user directly from your Dashboard.

## Steps {#steps}

1. On your Dashboard, go to **Data** > **Users**.
1. Open the user you need to deactivate and deactivate them.

If the user doesn't meet the [deactivation conditions](/users/guides/user-operations/deactivate#before-you-start), the Dashboard displays an error and the user isn't deactivated.
Note that if the user is linked to an enabled [account membership](/accounts/concepts/memberships), you need to disable the membership first.

## Find deactivated users {#find}

Deactivated users don't appear in the default user list.
To review them, filter the user list by **status**.
The user's deactivation date is displayed in their detail view.
