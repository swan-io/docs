:::danger Open Swan pages in the top-level browser only
Never embed Swan's authorization, consent, or sensitive card information pages in an iframe or a WebView, and never open them in a popup (for example, with `window.open`). Swan no longer supports these flows.

Instead, redirect the user to the URL:

- On the web, in the current browser tab.
- In a mobile app, in an in-app browser tab (`SFSafariViewController` on iOS, Chrome Custom Tabs on Android).
:::
