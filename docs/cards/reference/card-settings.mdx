# Card settings

<p className="ia-lede">The settings that manage a <Term id="card-product">card product</Term> and all the virtual, physical, and digital cards associated with it.</p>

## Settings {#settings}

Each setting shows whether you update it from the Dashboard (<Yes />) or with the API.
To update settings, follow the guide to [update card settings](/cards/guides/lifecycle/update).

| Setting | Explanation | Dashboard | API |
| --- | --- | :---: | :---: |
| Name | You can name the card product for easy reference from your Dashboard. | <Yes /> | <No /> |
| Allow physical cards | Decide whether physical cards are allowed to be issued for this card product. | <Yes /> | <No /> |
| Suspend | Suspend this card product. Your users won't be able to add new cards with this card product. You'll need to contact Swan Support to reactivate the card product. | <Yes /> | <No /> |
| `cardContractExpiryDate` | Date you'd like the card to expire.<br /><br />Leave it empty if you don't want to set an expiration date, in which case, cards are renewed automatically every three years. Refer to [renewal and expiry](/cards/concepts/virtual#renewal) for details. | <No /> | <Yes /> |
| `international` | Allow or disable payments outside of the account holder's country. Cardholders can still pay using other currencies: a cardholder in France can only make payments in France, but in euros as well as other currencies. | <No /> | <Yes /> |
| `withdrawal` | Allow or disable cash withdrawals, such as at ATMs. | <No /> | <Yes /> |
| `nonMainCurrencyTransactions` | Allow or disable transactions outside of the card's currency. Payments can still be made in other countries, but not using other currencies: a cardholder in France can make payments in euros in the United Kingdom, but not in GBP (Pound Sterling). | <No /> | <Yes /> |
| `eCommerce` | Allow or disable transactions on eCommerce sites or for online transactions. | <No /> | <Yes /> |
| `spendingLimit` | Fixed by the account holder or qualifying account member, within the [limits set by Swan](/cards/reference/spending-limits#limits-swan). | <No /> | <Yes /> |

## Custom card expiry {#custom-expiry}

You can customize the expiration date for virtual cards using the `cardContractExpiryDate` field.

:::caution Maximum expiry
Custom expiry dates must be at most 3 years from card creation.
:::

This setting is available in the following mutations:

- [`addCard`](https://api-reference.swan.io/mutations/add-card/): add a single virtual card.
- [`addCards`](https://api-reference.swan.io/mutations/add-cards/): add multiple virtual cards.
- [`addCardsWithGroupDelivery`](https://api-reference.swan.io/mutations/add-cards-with-group-delivery/): add multiple cards with group delivery.
- [`updateCard`](https://api-reference.swan.io/mutations/update-card/): update an existing card.
- [`addSingleUseVirtualCard`](https://api-reference.swan.io/mutations/add-single-use-virtual-card/): add a single-use virtual card.
- [`addSingleUseVirtualCards`](https://api-reference.swan.io/mutations/add-single-use-virtual-cards/): add multiple single-use virtual cards.

:::warning One-off SUV cards
For one-off single-use virtual cards with the spending limit `period` set to `Always`, cards automatically expire 30 days after creation. This overrides any custom expiry date you set.
:::
