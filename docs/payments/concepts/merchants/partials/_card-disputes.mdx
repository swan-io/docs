Cardholders might request a chargeback, which opens a dispute.
Merchants can view the dispute right away: the transaction status and the merchant's balance update to reflect it. For online cards, the payment object status moves to `Disputed`; for in-person cards, the payment is `Canceled`.

Disputes can't be handled through Swan's API or Dashboard.
To respond to a dispute, ask your merchant to [submit a request](https://supportform.swan.io/) to the Swan Support team.
