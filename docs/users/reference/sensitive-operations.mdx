# Sensitive operations

Sensitive operations are mutations that typically require your user's [consent](/users/concepts/consent) before execution. Some may not, depending on context (for example, `suspendAccountMembership`).

All links lead to the mutation's API Reference page.
The **Server-to-server** column indicates whether the mutation is eligible for [server-to-server consent](/users/concepts/consent/server-to-server): eligible (<Yes />) or not eligible (<No />).

## Accounts and onboarding {#sensitive-accounts}

| Mutation | Server-to-server |
|---|---|
| [`closeAccount`](https://api-reference.swan.io/mutations/close-account/) | <No /> |
| [`openAccount`](https://api-reference.swan.io/mutations/open-account/) | <Yes /> |
| [`finalizeAccountHolderOnboarding`](https://api-reference.swan.io/mutations/finalize-account-holder-onboarding/) | <Yes /> |
| [`finalizeOnboarding`](https://api-reference.swan.io/mutations/finalize-onboarding/) (deprecated) | <Yes /> |
