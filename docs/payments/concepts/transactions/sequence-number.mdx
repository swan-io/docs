# Sequence number

<p className="ia-lede">Swan assigns an incrementing <code>sequenceNumber</code> to every <code>Booked</code> <a href="/payments/concepts/transactions">transaction</a>, giving you a reliable way to order transactions and spot any gaps.</p>

## How it works {#how-it-works}

Swan assigns a `sequenceNumber` to every `Booked` transaction.
The number increments by 1 with each new booked transaction, giving you a reliable way to order transactions and spot any gaps.

`sequenceNumber` is also used to order `Booked` transactions on [account statements](/accounts/concepts/account/statements).

`sequenceNumber` returns `null` for all [transaction statuses](/payments/concepts/transactions/statuses#transactions-statuses) other than `Booked`.

## Query the sequence number {#query}

`sequenceNumber` is available in `BookedTransactionStatusInfo.balanceAfter` when you query a transaction's `statusInfo`.

```graphql {6} showLineNumbers
query GetTransactionSequenceNumber {
  transaction(id: "$YOUR_TRANSACTION_ID") {
    statusInfo {
      ... on BookedTransactionStatusInfo {
        balanceAfter {
          sequenceNumber
          amount {
            value
            currency
          }
        }
      }
    }
  }
}
```

## Availability {#availability}

:::note Migration in progress
`sequenceNumber` is populated for all newly Booked transactions.
Backfilling older transactions is in progress, so historical transactions may not yet have a value.
:::
