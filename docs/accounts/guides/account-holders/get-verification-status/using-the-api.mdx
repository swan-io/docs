# Get account holder verification status using the API {#get-status}

Call the `accountHolder` query to get an <Term id="account-holder">account holder</Term>'s verification status.
Add `verificationStatusInfo` to get more details about specific statuses.
This guide gives more details about an account holder verification with the status `WaitingForInformation`.

## Guide {#guide}

1. First, retrieve the required `accountHolderId`: on your Dashboard, go to **Data** > **Account holders**, locate the account holder you need, and click to copy their ID.
1. Call the `accountHolder` query.
1. Enter the `accountHolderId` retrieved in step 1.
1. Add the `verificationStatusInfo` object.
1. Add the `AccountHolderWaitingForInformationVerificationStatusInfo` union to get information about the `WaitingForInformation` status for this account holder verification.
1. Add `verificationRequirements` > `id` and `type`.

:::info `verificationRequirements`
Review possible `verificationRequirements` in the [waiting for information requirements](/accounts/concepts/account-holders/verification-statuses#waiting-for-info).
:::

```graphql {2-3,5,9-11} showLineNumbers
query WaitingForInfoStatus {
  accountHolder(id: "$ACCOUNT_HOLDER_ID") {
    verificationStatusInfo {
      status
      ... on AccountHolderWaitingForInformationVerificationStatusInfo {
        __typename
        waitingForInformationAt
        status
        verificationRequirements {
          id
          type
        }
      }
    }
  }
}
```
